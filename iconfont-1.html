字体方式的写法

给元素加上 fa-solid 与具体图标名两个 class，图标即可作为文字参与排版，字号与颜色直接由 CSS 控制。

<i class="fa-solid fa-feather"></i>
.lbw_icon-cell i { font-size: 26px; color: var(--lbw_ink); }
